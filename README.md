# Simbacord

Client Discord custom basé sur Equicord, avec installeur Windows et auto-update intégré.

## Installation

1. Télécharge `simbacordsetup.exe` depuis la [dernière release](../../releases/latest)
2. Lance-le → le dossier `Simbacord` est créé sur ton bureau
3. Un raccourci `Simbacord` apparaît sur le bureau et dans le menu démarrer

## Auto-update

L'app check les nouvelles versions au démarrage et se met à jour automatiquement.
Rien à faire — relance Simbacord et t'es à jour.

## Désinstaller

Via **Ajout/Suppression de programmes** Windows → Simbacord → Désinstaller.
